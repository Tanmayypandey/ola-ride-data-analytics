# Ola Ride Data Analytics

## Project Overview
Analysis of 150,000 Ola ride booking records to understand booking
performance, revenue, cancellations, vehicle performance and customer demand.

## Tech Stack
- Python
- Pandas
- Matplotlib
- Power BI

## Project Workflow
1. Data Cleaning
2. Data Validation
3. Feature Engineering
4. Exploratory Data Analysis
5. Data Visualization
6. Business Insights
7. Power BI Dashboard

## Key Insights
- 150,000 total bookings analyzed
- 93,000 completed rides
- 62% completion rate
- Driver cancellations were the largest cancellation category
- Peak booking demand occurred around 6 PM
- Auto generated approximately ₹12.88M in total revenue
